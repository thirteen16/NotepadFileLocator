# NotepadFileLocator

在 Windows 11 自带记事本中快速按两次 **Esc**，即可在文件资源管理器中定位当前标签的文件。资源管理器直接在前台显示，并选中该文件。

## 构建与运行

需要 Windows 11 x64 和系统自带的 .NET Framework 4.8，无需安装 Python、AutoHotkey 或 .NET SDK。

在项目目录打开 PowerShell，运行：

```powershell
.\build.ps1
```

生成后双击 `NotepadFileLocator.exe`。程序在系统托盘运行，重复启动只保留一个实例。移动或分发程序时，请同时保留同目录下的 `NotepadFileLocator.exe.config`。

## 使用

1. 在记事本中选中需要定位的文件标签。
2. 在文档编辑区快速按两次 **Esc**（间隔不超过 450 毫秒）。
3. 资源管理器在前台显示并选中文件，不会永久置顶。

新文档尚未保存时，会打开另存为窗口；保存后再按两次 Esc 即可定位。右键托盘图标可查看使用方法、暂停快捷键、设置开机自动启动或退出。

## 注意事项

- 支持多个标签、多个窗口和不同目录的同名文件；定位不会保存已有文件的未保存修改。
- 单次 Esc 保持原功能，长按不会触发。文件被移动、删除或无法访问时会提示失败。
- 适用于 Windows 11 的新版记事本，不支持 Notepad++、VS Code 和旧版记事本。
- 已适配记事本 `11.2607.14.0 x64`：核对程序指纹后，只读获取当前标签路径。其他版本回退到标签信息／悬停提示读取，可能短暂移动鼠标并等待约 1～2 秒。
- 通常使用普通权限即可；若记事本以管理员权限运行，定位器也需要相应权限。
- 开机启动默认关闭；移动程序后，需要重新设置开机启动。
- 不读取文档正文或历史会话，不使用剪贴板，不联网。

## 项目文件

- `src/`：快捷键、路径读取、资源管理器定位和托盘界面源码。
- `build.ps1`：使用系统自带 C# 编译器构建。
- `app.manifest`：应用权限和 DPI 配置。
- `NotepadFileLocator.ico`：程序及托盘图标。
- `NotepadFileLocator.exe.config`：.NET Framework 运行时配置。
